## 📌 Executive Summary

Despite the global acceleration of digital technologies, cloud infrastructure, and electronic workflows, **global paper manufacturing remains at historic highs—exceeding 420 million metric tons annually**.

This project provides an exhaustive environmental research platform and interactive digital toolkit investigating:
1. **The Life-Cycle Costs of Paper**: Industrial freshwater depletion (up to 10 liters per A4 sheet), toxic chlorine bleaching effluents, deforestation of high-conservation forests, and landfill methane release ($CH_4$).
2. **Paper vs. Digital Dilemma**: Objective life-cycle trade-offs analyzing electronic waste, data-center server carbon footprints, cloud energy efficiency, and renewable hosting alternatives.
3. **The 5 R's & Green AI Paradigm**: Practical industrial transition pathways combining Rethink, Reduce, Reuse, Recycle, and Remanufacture with sustainable IT policies.
4. **Interactive 3D Narrative & Documentary**: Real-time WebGL procedural 3D simulations, chaptered educational documentary video, and a 13-page academic research report viewer.

## 🛠️ Technology Stack

- **Markup & Semantics**: HTML5 with ARIA accessibility roles and OpenGraph meta tags.
- **Styling**: Vanilla CSS3, Custom Properties (CSS variables), CSS Grid, Flexbox, glassmorphic filters, and WCAG AA compliant color contrast.
- **3D Graphics Engine**: [Three.js](https://threejs.org/) (r128) rendering procedural geometries, PBR lighting, and scroll-synchronized cameras.
- **Data Visualization**: [Chart.js](https://www.chartjs.org/) for responsive charts (carbon footprints, recycled vs virgin pulp, organizational trends).
- **Video & Media**: HTML5 Video API with chapter marker cues and custom thumbnail posters.
- **SEO & Discoverability**: Semantic heading hierarchies, `sitemap.xml`, `robots.txt`, and canonical GitHub Pages metadata.

## 🚀 Running the Project Locally

Because the project is built with clean standards-compliant HTML5, CSS3, and JavaScript, no build step, compiler, or Node package installation is required.

### Option 1: Python Built-In HTTP Server (Recommended)
Open a terminal in the project directory:
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

### Option 2: VS Code / Antigravity IDE Live Server
1. Open this repository folder in VS Code or Antigravity IDE.
2. Right-click [`index.html`](file:///c:/Users/karti/Downloads/Environment-CA2-final/Environment-__CA--2/index.html).
3. Click **"Open with Live Server"**.

### Option 3: Node.js `npx serve`
```bash
npx serve .
```

## 🌐 GitHub Pages Deployment

The live website is automatically served via GitHub Pages at:
👉 **`https://kartikagrawal2200.github.io/Environment-CHE-110-project/`**

### To deploy or update your GitHub Pages:
1. Stage, commit, and push your changes to `main`:
   ```bash
   git add .
   git commit -m "feat: update documentation, documentary, and interactive modules"
   git push origin main
   ```
2. In your GitHub repository:
   - Navigate to **Settings** &rarr; **Pages** (under *Code and automation* in the sidebar).
   - Under **Build and deployment** &rarr; **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and root directory `/(root)`.
   - Click **Save**.
3. Your updated site will be live within 1–2 minutes!
